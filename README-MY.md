# Stage Show APK

Termux မလိုဘဲ ဖုန်းထဲမှာပဲ Stage Show server ကို run တဲ့ Android app ပါ။

## သုံးနည်း

1. APK ကို install ပြီး app ကိုဖွင့်ပါ။
2. `🎛 Control` မှာ TikTok LIVE ကို အရင် စပြီး username ချိတ်ပါ။
3. `🎤 Show` ကိုဖွင့်ပြီး `အသံဖွင့်ရန်` ကိုနှိပ်ပါ။
4. `⛶ အပြည့်` နှိပ်ပြီး TikTok မှာ Mobile gaming LIVE စပါ။ Show screen ကိုနှိပ်ရင် control bar ပြန်ပေါ်လာမယ်။
5. နောက် device ကနေ Control သုံးချင်ရင် Wi-Fi တူတူမှာ `http://<phone-IP>:3000/live/control.html` ကိုဖွင့်ပါ။

## မှတ်ချက်

- TikTok ရိုးရိုး camera LIVE ထဲကို overlay တိုက်ရိုက်ထည့်တာ မဟုတ်ပါ။ Mobile gaming screen-share နဲ့ ပြရပါတယ်။
- Stage က TikTok 9:16 safe band ထဲမှာ အရေးကြီး စာတွေ မပြတ်အောင် fit လုပ်ထားပါတယ်။
- arm64-v8a ဖုန်းများအတွက် build ထားပါတယ်။
